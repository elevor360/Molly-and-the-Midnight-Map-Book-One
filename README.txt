ELEVOR360D — MOLLY AND THE MIDNIGHT MAP
Molly's Adventures — Book Two
Version 1.0.0

THE SECOND MOLLY ADVENTURE
A new, complete 50-page story of approximately 9,500 words across 10 chapters.
Molly returns with Pip, Bramble, Luma, Fern, Quill, Nettle and Juniper. The main
mystery is resolved, and the last chapter deliberately opens the next adventure.
The final words are TO BE CONTINUED. Book Three is not part of this package.

Continuity: Molly retains her rainbow hair, pink sunglasses, tie-dye scarf,
peace charm and the plain cream bow from Book One. The previous story's
recovered colours, quiet bank, repaired bridge and character friendships remain.

SIX ILLUSTRATIONS
An original cover plus five interior images at story pages 5, 10, 16, 26 and 50.
A matching 1672 x 941 promotional banner and short website description are
included. Artwork is interpreted rather than a technical depiction of each event.

READER FEATURES
Saved position, multiple bookmarks, chapter navigation, direct page selection,
next/previous controls, adjustable text size and three reading themes. Offline
reading after a successful first online visit. Installation button and guidance.
No account, payments or analytics. The same standalone reader format as Book One.
This book has its own progress key and cache identity, separate from Book One.

The 50 numbered story pages exclude the cover. Pages scroll on phones and at
larger text sizes, so no text is cut off. Progress stays in this device/browser;
clearing browser data removes it, and it does not sync to other devices.

UPLOAD TO GITHUB PAGES
1. Extract the ZIP.
2. Create a NEW public repository, for example:
   Elevor360D-Molly-Midnight-Map
3. Upload the CONTENTS of the extracted folder, preserving assets/.
   index.html should be at the repository root, not inside a wrapping folder.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Wait until GitHub displays its published HTTPS address.
6. Open that address online, wait for Available offline and test the reader.
7. Add the published URL to Books & Reading on your Elevor360D website.
   Suggested unique app ID: molly-midnight-map

Do not overwrite the first Molly app or your app store. This package is a
separate Book Two. Alternatively, place all files together in a NEW subfolder
on an existing HTTPS website. The service worker is scoped to that folder.

INSTALLATION
Android: Chrome > Install book, or browser menu > Install app / Add to Home
screen. iPhone/iPad: Safari > Share > Add to Home Screen. Desktop: Chrome/Edge
install icon or browser menu. The button hides in installed display mode.
Browser reading also works. Installation availability depends on the browser.

OFFLINE READING
Visit online once, wait for Available offline, then close the app and reopen
without an internet connection. The story and illustrations remain available.
Opening index.html as a computer file allows basic reading, but installation
and service workers require HTTPS hosting (localhost for development).

FILES
story.txt: editable manuscript with explicit page and chapter boundaries.
story.json and story-data.js: manuscript content prepared for the reader.
index.html / app.js / styles.css: the reader.
assets/: illustrations and installation icons.
Molly_Midnight_Map_Banner.jpg: website promotional banner (1672 x 941).
WEBSITE-LISTING.txt: copy-ready title, description and app ID.
ART-NOTES.txt: illustration production notes.

UPDATES
After editing, change the cache version suffix in sw.js and upload all changed
files. An online visit installs the new cache; an additional reload may be
needed. Keeping the same origin/path preserves this book's browser storage.

STORY AND ART
Original fantasy fiction created for Elevor360D. No author identity has been
invented. Illustrations were generated from the established Molly visual design
in newly composed scenes. There are no links claiming Book Three is available.
